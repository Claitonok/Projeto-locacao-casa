# 🏠 Hospedagem Home Page

**Hospedagem Home Page** é um projeto web de apresentação e locação de casas, ideal para mostrar imóveis disponíveis para hospedagem ou aluguel.

> 🔎 Uma página simples e funcional para exibir casas, com foco em layout moderno e experiência de usuário.

---

## 📌 Descrição

Este projeto foi desenvolvido como uma aplicação de frontend para um site de **locação/hospedagem de casas**. A ideia é permitir que visitantes vejam uma lista de propriedades com imagens, informações e opções de detalhes.

O projeto é ideal para portfólios, demonstrações de design responsivo e projetos de estudo em HTML, CSS e JavaScript.

---

## 💡 Funcionalidades

- 🏡 Exibição de imóveis disponíveis;
- 📷 Galeria de imagens para cada casa;
- 📋 Informações sobre cada imóvel (descrição, preço, localização, etc.);
- 📱 Design responsivo para dispositivos móveis;
- ✨ Layout moderno e atrativo.

---
